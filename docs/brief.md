# Brief para el proyecto sobre el Suicidio en Colombia.
1. **Usuario:** Lo puede usar el gobierno, organizaciones no gubernamentales, periodistas, etc.
2. **Fuente:** master.csv, Boletines estadísticos mensuales de medicina forense.
3. **Destino:** Una tabla de suicidios por departamento y año, o también una especie de tablero que se actualiza a medida que se van añadiendo los datos para observar el comportamiento de manera mensual o también una api del estilo de https://www.worldometers.info/es/poblacion-mundial/poblacion-colombia/, pero con el tema del suicidio.
4. **Dos KPI:** Suicidios por día, Grupo etario que más se suicida.
5. **Frecuencia:** Mensual, Anual, ect.
6. **Calidad mínima:** Sin datos de suicidios duplicados.
7. **Terminó bien:** Corre dos veces seguidas con el mismo resultado, y sus dos KPI coinciden con una cuenta manual.
8. **Fuera:** Políticas públicas del país, también está fuera de nuestro poder el cómo se recolectan los datos, ahí entrarí el subregistro.
